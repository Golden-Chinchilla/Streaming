产品需求文档 (PRD): 高级 Sankey 图可视化编辑器

1. 产品概述
   一款面向数据分析师、科研人员和财务人员的专业可视化工具。用户可以通过导入 CSV/JSON 或直接编写代码，快速生成具有设计感的桑基图（Sankey Diagram），并支持高度自定义的样式导出。

2. 核心目标
   极简体验：参考 Google Material Design 3 规范，降低复杂数据的上手难度。
   高效输入：支持文件拖拽与实时代码编辑双模式。
   所见即所得：数据修改后，图表亚秒级渲染更新。
3. 功能需求
   3.1 数据输入管理 (左侧面板)
   文件导入 (Source Tab)：
   支持 .csv, .json, .xlsx 格式。
   提供拖拽上传区域。
   导入后显示数据概览（前 5 行预览）。
   实时编辑器 (Editor Tab)：
   支持 JSON 数组格式（如 nodes 和 links）。
   支持简单 CSV 文本编辑（source, target, value）。
   语法高亮：针对不同数据类型显示不同颜色。
   实时同步：点击“Sync”或开启“Auto-sync”后，右侧画布立即更新。
   错误检查：对格式错误的 JSON/CSV 提供行级报错提示。
   3.2 核心画布 (中央区域)
   交互式图表：
   节点拖拽：用户可上下移动节点位置。
   悬浮提示 (Tooltip)：鼠标经过路径时显示来源、去向及具体数值。
   自动布局：提供一键排列按钮，优化路径交叉。
   响应式缩放：支持鼠标滚轮缩放和画布平移。
   3.3 样式配置 (右侧面板)
   全局设置：
   主题切换（明亮模式/深色模式）。
   配色方案（预设 Google 调色盘、渐变色、分类色）。
   节点属性：调整节点宽度、间距、圆角。
   路径属性：调整路径透明度、弯曲度（Curvature）、悬浮高亮效果。
   标签设置：字体选择（Roboto）、字号、颜色、显示位置（内部/外部）。
4. 交互逻辑
   用户进入首页：可选择“从模板开始”或“上传数据”。
   数据映射：系统自动识别 CSV 列名，尝试匹配 source, target, value。
   样式调整：用户在右侧面板微调颜色，画布实时反馈。
   导出分享：支持导出为 PNG, SVG, 或生成可嵌入的 HTML 代码。
5. 性能与技术指标
   渲染引擎：基于 D3.js 或 Canvas，确保在处理 500+ 节点时不卡顿。
   字体库：优先调用 Roboto 和 Google Sans。
   响应式：编辑器需适配 1440px 及以上的主流桌面分辨率。
6. 后续规划 (Roadmap)
   V1.1：增加多级 Sankey（多层级流向）。
   V1.2：多人在线实时协作编辑。
