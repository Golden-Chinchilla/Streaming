# Assets

This folder contains visual assets used across the app.

## Structure
- `brand/`: logos, brand marks, identity assets.
- `illustrations/`: scene illustrations for home, onboarding, and empty states.
- `icons/`: custom business icons not covered by icon libraries.
- `diagrams/`: diagram/editor related SVG templates and references.
- `decorations/`: backgrounds, glows, ornaments, separators.

## Naming
- Use `kebab-case`.
- Keep names descriptive and domain-oriented.
- Example: `empty-state-no-documents.svg`.

## Licensing
- Track source and license in each subfolder README.
- Do not add assets without clear usage rights.
