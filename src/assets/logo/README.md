# Logo Assets

- `streaming-logo.svg`: full horizontal logo (mark + wordmark), suitable for headers and landing pages.
- `streaming-mark.svg`: icon-only mark, suitable for favicon/app icon/avatar.

Both files use the project's visual language:
- olive/neon brand axis (`#7B9141`, `#BFD941`)
- flow accents (`#D4A373`, `#6F8A75`)
- rounded geometry and soft shadow
